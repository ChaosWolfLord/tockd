Delete your Tockd data

Tockd (Android app by ChaosWolfLord) has no online accounts and no servers. Everything it stores is on your own phone, so you delete it there. The developer holds no copy to delete.

Delete everything on the phone

  1. Open Tockd and go to Settings (Home, then the profile badge, then the gear).
  2. Under This phone, tap Delete account, then Delete.
  3. If an override code is set, the supervisor types it.

This deletes the name, chores, badges, streaks, schedules, screen-time history, workout progress, the override code and the override history. Tockd shows that the account was deleted, then starts again at setup.

Uninstalling Tockd also deletes all of it.

Data kept elsewhere

  • Health Connect: workouts Tockd wrote stay in Health Connect. Delete them in the Health Connect app, where each app's data can be removed.
  • A linked supervisor's phone: it keeps recent chore notifications. On the supervisor's phone, tap Unlink next to the person, or delete the account there too.

Need help?

Open an issue on GitHub. Please don't include personal details; the developer can't see any of your data.
