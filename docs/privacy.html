Tockd Privacy Policy

Effective 22 October 2026

Summary

Tockd keeps everything on your own devices. There are no accounts, no ads, no analytics and no Tockd servers. The developer never receives your information.

What Tockd stores on the phone

A first name, chores, badges, streaks, block schedules, earning rules and settings.

The supervisor's supervisor's code, stored only as a salted hash, so the code itself can't be read back.

The code history: when the code was used and what for.

Daily totals for the weekly report: minutes earned and spent, steps, and screen time per app.

Workout progress: exercises, reps, sets and any gym weights typed in.

The Accessibility service (the blocker)

Tockd uses Android's Accessibility service to block apps. It isn't an accessibility tool for people with disabilities.

It sees which app is on screen and, in supported web browsers, the address in the address bar, so it can show the lock screen over blocked apps and websites.

On Tockd's own switch in Android's accessibility settings, it looks for a few words, such as the app's name, so the blocker can't be switched off without the supervisor's code. Tockd can always be uninstalled.

It counts the minutes spent in blocked apps. It doesn't read messages, passwords or what you type, doesn't take screenshots, and doesn't save or send what's on the screen.

You turn it on yourself in Android's settings, after Tockd explains this, and you can turn it off there. If protection is set up, the supervisor's code may be needed first.

Usage access

With Usage access, Tockd reads how long each app was used, to show the Screen time page and the weekly report. This stays on the phone.

Health Connect

If you connect Health Connect, Tockd reads steps and active calories (for goal progress and unlock minutes) and writes finished workouts. This stays on the phone and in Health Connect, and you can disconnect or delete it in Health Connect at any time.

What leaves the phone

Update checks (the version downloaded from GitHub): Tockd downloads version information and new versions from GitHub. GitHub can see your IP address, as with any website.

A linked supervisor's phone (optional): over your home Wi-Fi, the supervised phone sends the person's first name, the names and times of ticked chores, which are waiting for a spot check, and the time Tockd's blocker was switched off or back on. The supervisor's phone sends back its answers. Messages are signed so they can't be faked, but they aren't encrypted. The supervisor's code is never sent.

Nothing goes to the developer or to any other company. Tockd doesn't sell or share information.

Who it's for

Tockd is a family app: a parent or guardian is the supervisor for their child or teen. It collects nothing from anyone, children included, for the developer: everything stays on your family's own devices.

Deleting your information

Settings, then Delete account, deletes everything Tockd stores on the phone (it needs the supervisor's code if one is set). Uninstalling Tockd also deletes it.

Workouts written to Health Connect stay there until you delete them in Health Connect.

Changes

If this policy changes, the new version will be in the app and on this page, with a new date.
